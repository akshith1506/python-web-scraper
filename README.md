Python Web Scraper for Headlines and Quotes

Project Description

This project is developed using Python to scrape web data and save quotes and their authors into text and JSON files.

Features

- Extracts quotes and authors from a website.
- Saves scraped data into a text file ("quotes.txt").
- Saves scraped data into a JSON file ("quotes.json").
- Uses Python for automated web scraping.
- Includes basic error handling.

Technologies Used

- Python
- Requests
- BeautifulSoup
- JSON

Requirements

Install the required libraries using:

pip install -r requirements.txt

How to Run

1. Install Python.
2. Install the required libraries.
3. Open the project folder in VS Code.
4. Run the following command:

python scraper.py

Output Files

- "quotes.txt" – Stores quotes and authors in text format.
- "quotes.json" – Stores scraped data in JSON format.
